# Open-source project files — why each exists

This package is intended for a public repository (for example <https://github.com/johnsonmima/mima-ai-prompt>).
The files below are the standard open-source “kit” for a Python library on PyPI.
Each entry explains **what** the file is and **why** it is required or strongly recommended.

| File / folder | Why it is needed |
| --------------- | ------------------ |
| `LICENSE` (MIT) | Legal permission for others to use, modify, and redistribute. |
| `README.md` | First page for GitHub and PyPI: what the library supports today. |
| `CHANGELOG.md` | SemVer-friendly history (Keep a Changelog). |
| `CONTRIBUTING.md` | How to build, test, branch, and open PRs. |
| `PR.md` | Ordered pull request procedure: `main`, branch names, CI, version, merge, tag. |
| `CODE_OF_CONDUCT.md` | Behavioral expectations and enforcement. |
| `SECURITY.md` | Private vulnerability reporting; GitHub Security tab. |
| `GITHUB.md` | Maintainer guide: Actions, CI jobs, PyPI Trusted Publishing, branch protection. |
| `.gitignore` | Keeps `.venv/`, `dist/`, coverage, secrets, `TEMP.md`, IDE junk out of git. |
| `.editorconfig` | Shared formatting so multi-contributor PRs are not drowned in whitespace noise. |
| `pyproject.toml` + `uv.lock` | Package metadata and locked deps; CI uses `uv sync --locked`. |
| `src/mima_ai_prompt/` | Library source (src layout). |
| `tests/` | Proves behavior; CI enforces ≥ 95% line coverage. |
| `.github/workflows/ci.yml` | Automated test/pack on every PR. |
| `.github/workflows/release.yml` | Tag-based PyPI publish (OIDC Trusted Publishing). |
| `.github/dependabot.yml` | Automated dependency update PRs (uv + Actions), semiannual, majors ignored. |
| `.github/CODEOWNERS` | Auto-requests reviews when protection requires code owners. |
| `.github/PULL_REQUEST_TEMPLATE.md` | Consistent PR checklist. |
| `.github/ISSUE_TEMPLATE/*` | Structured bug/feature reports; routes security elsewhere. |
| `src/mima_ai_prompt/py.typed` | Marks the package as typed for type checkers. |

## Intentionally **not** tracked by git

| Path | Why ignored |
| ------ | ------------- |
| `.venv/`, `dist/`, `__pycache__/`, coverage | Regenerated by sync/test/build. |
| `TEMP.md` | Maintainer first-publish notes (GitHub UI + PyPI CD); local only. |
| `.env`, keys | Secrets must never be published. |
| `.idea/`, most `.vscode/` | Personal IDE state. |

## Naming consistency

PyPI, GitHub, and badges use **`mima-ai-prompt`**. The Python import and `src/` package are **`mima_ai_prompt`**.

This library is the Python counterpart of the .NET package [Mima.AI.Prompt](https://www.nuget.org/packages/Mima.AI.Prompt). Canonical JSON shapes are aligned so hosts can share prompt documents across languages.

## Package layout

`src/mima_ai_prompt/` uses domain packages (`roles/`, `content/`, `messages/`, `models/`, `templates/`, `catalog/`, `validation/`, `serialization/`, `versioning/`) with snake_case modules and package `__init__.py` re-exports. Single-class modules (`builder.py`, `conversation.py`, `localization.py`, `exceptions.py`) stay flat. Private helpers live in `_utils.py`. The public surface remains `from mima_ai_prompt import ...`.
